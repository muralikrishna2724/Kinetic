The run's shape as a vector, not a map tile. No API key, no network, identical in both themes — and at card size a tile layer is noise anyway.

Projection

Longitude degrees are scaled by cos(latitude) before projection. Without that correction a north–south route renders visibly squashed and the shape stops being an honest record of where you went. Aspect ratio is preserved and the path is centred in its box.
